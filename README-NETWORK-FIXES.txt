ScriptFlow Pro - Firebase Network Resilience Fixes

Fixed:
1. Firebase Firestore reads now have a 7-second application timeout so the UI does not wait indefinitely for DNS/network failures.
2. Local fallback data is hydrated before network-dependent Firebase reads.
3. Firestore connectivity errors automatically switch the app to local/offline mode instead of showing a fatal Data Load Error.
4. Firestore network is paused on browser offline events and re-enabled when the browser reports online again.
5. Google redirect network failures are logged quietly rather than displayed as application errors.
6. Firestore subscription failures hydrate the existing local fallback data.
7. Existing Firebase project configuration, data schema, UI structure, TypeScript architecture, and features are preserved.

Important:
- ERR_NAME_NOT_RESOLVED means the browser/device cannot resolve the Firebase hostname. No application code can make DNS work, but the app now remains usable and preserves local data until connectivity returns.
- The chrome-extension://invalid asynchronous listener error is generated by a browser extension/content script and is not caused by ScriptFlow Pro. Test in Incognito or with extensions disabled if it persists.

Render:
Build: npm install --include=dev --no-audit --no-fund && npm run build
Start: npm start
